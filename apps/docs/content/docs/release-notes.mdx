Releases are versioned with changesets and published to npm as `@sdods/*`.

## 0.2.0

First published release: `npm i -g @sdods/cli` installs SDODS as compiled packages, so there is no
longer a source checkout in `~/.sdods/app`.

- The installer defaults to the published packages; `--source git` clones a checkout for working
  on SDODS itself, and is never used as a silent fallback.
- `sdods init` scaffolds the demo project from assets shipped inside `@sdods/cli`.
- `sdods serve` ships the dashboard inside `@sdods/server`.

  0.1.0 was never released for this project; the version number was already taken on npm by an
  earlier, unrelated placeholder, so the first release is 0.2.0.
