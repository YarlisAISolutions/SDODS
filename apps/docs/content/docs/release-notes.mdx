Releases are versioned with changesets. Nothing has been released yet — there is no tag, and
`@sdods/*` is not on npm — so 0.1.0 below describes the current state of `main` rather than a
version you can install by number. Installing from source is the supported path until the first
release, which is [the November checkpoint](/docs/roadmap) on the roadmap; from then on each
release will also be tagged and published.

## 0.1.0 (unreleased)

- Monorepo with `@sdods/contracts`, `@sdods/core`, `@sdods/cli` and the `demo-shop` project.
- Six-layer configuration precedence with provenance, secret-literal refusal and `${VAR:-default}` interpolation.
- Organization → workspace → project → module hierarchy and named processes.
- `sdods project`, `env`, `config`, `doctor` commands.
- This documentation site.
