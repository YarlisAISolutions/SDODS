---
title: sdods completion
description: Print a shell completion script generated from the command tree.
---

```text
sdods completion bash|zsh|fish
```

The script is generated from the live commander metadata, so it always matches the installed version: top-level commands, subcommands, and the flags of each.

```bash
# bash
sdods completion bash > ~/.sdods-completion.bash
echo 'source ~/.sdods-completion.bash' >> ~/.bashrc

# zsh
sdods completion zsh > "${fpath[1]}/_sdods"
autoload -Uz compinit && compinit

# fish
sdods completion fish > ~/.config/fish/completions/sdods.fish
```

Exit code `2` for an unknown shell.
