---
title: sdods watch
description: Regenerate BDD specs on change and re-run them in interactive UI mode.
---

```text
sdods watch [-p <slug>] [-e <env>] [-t <expr>] [-l <layer>]... [-b <browser>]... [--no-ui] [--headed]
```

Two children run with the same `SDODS_*` environment that `sdods run` uses:

1. `bddgen --watch` regenerates `.features-gen/<slug>/<layer>` whenever a feature or step file changes.
2. the suite in interactive UI mode (or watch mode with `--no-ui`), restricted to the generated targets of the selection.

| Flag                         | Meaning                                      |
| ---------------------------- | -------------------------------------------- |
| `-p`, `-e`, `-t`, `-l`, `-b` | same selection flags as `sdods run`          |
| `--no-ui`                    | terminal watch mode instead of the UI window |
| `--headed`                   | headed browsers in terminal watch mode       |

```bash
sdods watch -p demo-shop -e staging -l ui -b chromium -t @smoke
```

Stop with `Ctrl+C`; both children are terminated together. Exit code `2` when the selection matches no run target.
