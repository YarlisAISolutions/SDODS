## `report`

```text
automax report [--last|--run <id>] [--open] [--html|--dashboard|--allure] [--json]
automax report ingest --run-id <id> [-p <slug>] [--manifest <file>] [--format auto|cucumber|pw-json] <files...> [--replace]
                      [--server <url> --token <token>]
automax report html --run-id <id>
automax show-report [--run <id>]
automax trace <zip|runId>
```
