title: sdods project
description: Create and list projects.
---

## `project list`

```text
sdods project list [--matrix] [--shards <n>]
```

Prints slug, name, layers, browsers, environments (missing files are marked) and the default environment. `--matrix` emits a CI matrix of project × browser × shard as JSON.

```bash sdods-verify
bun run sdods project list
bun run sdods project list --matrix --shards 2
```

## `project create`

```text
sdods project create <slug> [--name <name>] [--layers ui,api,hybrid,recorded] [--browsers chromium,firefox,webkit]
                      [--ui-url <url>] [--api-url <url>] [--env <name>] [--test-id <attr>] [--force]
```

| Flag                     | Default                                               |
| ------------------------ | ----------------------------------------------------- |
| `--layers`               | `ui,api,hybrid`                                       |
| `--browsers`             | `chromium`                                            |
| `--ui-url` / `--api-url` | `http://localhost:3000` / `http://localhost:3000/api` |
| `--env`                  | `local`                                               |
| `--test-id`              | `data-testid`                                         |

Writes `sdods.project.yaml`, `envs/<env>.yaml`, `.env.example`, `steps/fixtures.ts`, `steps/auth.ts`, a project step file, `pages/HomePage.ts`, `features/health.feature`, `features/ui/home.feature`, `data/common/users.csv`, `data/factories.ts`, empty `recorded/` and `har/` folders and a README. The slug must be lowercase letters, digits and dashes.
