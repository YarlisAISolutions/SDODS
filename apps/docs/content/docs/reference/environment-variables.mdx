---
title: Environment variables
description: Every variable SDODS reads.
---

| Variable                                                                                                                  | Used by                  | Meaning                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `SDODS_PROJECT`, `SDODS_ENV`                                                                                              | runtime                  | project and environment selection (`run` sets them for workers)                                               |
| `SDODS_LAYERS`, `SDODS_BROWSERS`, `SDODS_TAGS`                                                                            | `sdods.runner.config.ts` | selection passed from the CLI                                                                                 |
| `SDODS_RUN_ID`, `SDODS_ARTIFACTS_DIR`                                                                                     | runtime                  | run identity and location (default `.sdods/runs`)                                                             |
| `SDODS_CLI_OVERRIDES`                                                                                                     | runtime                  | JSON of explicit CLI flags (set by the CLI)                                                                   |
| `SDODS_LINT`                                                                                                              | runtime                  | `1` during lint's undefined-step pass                                                                         |
| `SDODS_UI_BASE_URL`, `SDODS_API_BASE_URL`                                                                                 | config                   | override base URLs                                                                                            |
| `SDODS_HEADED`, `SDODS_WORKERS`, `SDODS_SHARD`, `SDODS_RETRIES`                                                           | config                   | runtime overrides                                                                                             |
| `SDODS_SHOT_POLICY`, `SDODS_SHOTS_ONLY_ON_FAILURE`                                                                        | config                   | screenshot policy                                                                                             |
| `SDODS_HEAL`                                                                                                              | config                   | enable or disable healing                                                                                     |
| `SDODS_TRACE`, `SDODS_VIDEO`                                                                                              | config                   | Playwright trace and video modes (`evidence.trace`, `evidence.video`)                                         |
| `SDODS_HAR_MODE`, `SDODS_OFFLINE`, `SDODS_UPDATE_SNAPSHOTS`                                                               | config                   | HAR mode, offline guard, baseline refresh                                                                     |
| `SDODS_PROJECTS_DIR`                                                                                                      | registry                 | where projects live (default `projects`)                                                                      |
| `SDODS_LOG_LEVEL`, `SDODS_LOG_JSON`, `SDODS_DEBUG`                                                                        | logger                   | `silent`, `error`, `warn`, `info`, `step`, `debug`; JSON lines; stack traces                                  |
| `SDODS_ALLURE`, `SDODS_INGEST`                                                                                            | runtime                  | extra reporter; force ingest                                                                                  |
| `SDODS_AUTO_INSTALL_BROWSERS`                                                                                             | runtime                  | `1`: `sdods run` downloads missing test browsers first (same as `--install-browsers`; set by the desktop app) |
| `DB_DRIVER`, `DATABASE_URL`, `SQLITE_PATH`                                                                                | database                 | driver toggle                                                                                                 |
| `PORT`, `HOST`, `SESSION_SECRET`, `SDODS_PUBLIC_URL`, `AUTH_DISABLED`, `SDODS_MAX_CONCURRENT_RUNS`, `SDODS_INGEST_MAX_MB` | server                   | web server                                                                                                    |
| `SDODS_SERVER_URL`, `SDODS_TOKEN`                                                                                         | CLI                      | upload ingest through the server                                                                              |
| `SDODS_LLM_PROVIDER`, `ANTHROPIC_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_API_KEY`                                            | agents                   | adapter selection and provider keys                                                                           |
| `GITHUB_TOKEN`, `JIRA_EMAIL`, `JIRA_API_TOKEN`                                                                            | integrations             | default secret names (configurable per project)                                                               |
| `CI`                                                                                                                      | runtime                  | selects `retries.ci`                                                                                          |
