```yaml title="projects/demo-shop/envs/staging.yaml"
name: staging
ui: { baseUrl: https://www.saucedemo.com }
api:
  baseUrl: https://jsonplaceholder.typicode.com
  headers: { Accept: application/json }
  auth: { type: none }
users: { poolSize: 4 }
mail: { provider: mailpit, url: http://localhost:8025 }
vars:
  defaultProduct: Sauce Labs Backpack
  standardPassword: '${DEMO_SHOP_PASSWORD:-secret_sauce}'
use: { locale: en-US, timezoneId: America/New_York }
screenshots: { onlyOnFailure: false }
perf: { budgets: { pageLoadMs: 5000 } }
```

A load-test environment opts in explicitly. See [Load testing](/docs/guides/load-testing).

```yaml title="projects/demo-shop/envs/perf.yaml"
ui: { baseUrl: https://perf.shop.example.com }
api:
  baseUrl: https://api.perf.shop.example.com
  auth: { type: bearer, token: '${PERF_API_TOKEN}' }
load: { allowed: true, maxVus: 50, allowWrites: false }
```
