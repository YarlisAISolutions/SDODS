---
title: Roadmap
description: The phased plan and what is shipped.
---

Each phase ends runnable. Status is updated with every release; commands documented for an unshipped phase carry a badge.

| Phase | Scope                                                          | Status      |
| ----- | -------------------------------------------------------------- | ----------- |
| 0     | Monorepo, config precedence, registry, CLI skeleton            | done        |
| 1     | API layer end to end (no browser), `run`, `lint`, step library | in progress |
| 2     | UI layer, page objects, self-healing, dashboard                | in progress |
| 3     | Data providers, user pool, auth capture, hybrid                | in progress |
| 4     | Screenshot narratives, NDJSON                                  | in progress |
| 5     | Database, ingest, switch                                       | in progress |
| 6     | Recorder and HAR                                               | planned     |
| 7     | MCP server                                                     | planned     |
| 8     | Agents and insights                                            | planned     |
| 9     | Server, scheduler                                              | planned     |
| 10    | Web UI                                                         | planned     |
| 11    | GitHub, Jira, CI workflows                                     | in progress |
| 12    | Onboarding analysis, processes, cross-browser matrix           | planned     |
| 13    | Documentation site, packaging, `automax init`                  | in progress |

Details for every phase, including verification commands, live in `docs/ARCHITECTURE.md` in the repository.
